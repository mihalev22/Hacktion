# X<актион> ТехЗадание — frontend

React 19 + Vite + TypeScript. Запуск, сборка и прокси `/api` описаны в корневом [README.md](../README.md).

- `npm install` — зависимости
- `npm run dev` — dev-сервер на :5173 (проксирует `/api` на :8000)
- `npm run build` — типы (`tsc -b`) + продакшн-сборка в `dist/`
- `npm run lint` — oxlint
